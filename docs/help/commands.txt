Olive Petrel monitor commands
==============================

General:
  .help               Open help shell (topics from docs/help)
  tnfs                Open TNFS subshell (mount/list/get/umount/status)
  regs                Show registers
  mem <addr> [count]  Dump memory (octal)
  x <addr> [count]    alias for 'mem'
  dep <addr> <word|string>.. Deposit octal words or ASCII strings
  load <file>         Load a simple octal image (auto-detects S-records)
  .a <src.pa> [dest]  Assemble PAL source to an S-record file
  save <file>         Save core memory as a loadable image
  pc <addr>           Set the program counter
  step [count]        Execute instructions
  run [max]           Run up to max instructions (default 100000)
  trace [count]       Step and show registers after each instruction
  reset               Clear memory and registers
  stack               Show monitor stack and SP
  .                   Pop and print the top of the monitor stack
  +                   Pop two values, push sum (12-bit)
  -                   Pop two values, push difference (12-bit)
  @                   Replace TOS with memory at address TOS
  !                   Pop value and address, store value at address
  and                 Pop two values, push bitwise AND (12-bit)
  or                  Pop two values, push bitwise OR (12-bit)
  not                 Pop one value, push bitwise NOT (12-bit)
  quit                Exit the emulator

Input shortcuts:
  <octal>             Push a bare octal word onto the monitor stack

Devices:
  show dev            Show attached devices
  show dt             Show TC08 status
  dt0|dt1 att|attach <file> [new]    Attach or create a DECtape image
  dt0|dt1 read <block> <addr>        Read a 129-word block into memory
  dt0|dt1 write <block> <addr>       Write a 129-word block from memory
  rx0|rx1 att|attach <file> [new]    Attach or create an RX01/RX02 image
  rx0|rx1 read <track> <sector> <addr>   Read a sector into memory
  rx0|rx1 write <track> <sector> <addr>  Write a sector from memory
  lpt att|attach <file>              Attach a line printer output file
  tti read <file>                    Feed a file to TTI (EOF marker 0377)
  watchdog restart                   Restart the watchdog (placeholder)
